# Android — Capacitor / Build / Release

## Overview
The Android app is a Capacitor 8 wrapper around the built React SPA.
- App ID: `com.quickstackapp.quickstack`
- Deep link scheme: `quickstack://reset-password`
- SDK: `minSdkVersion 24`, `compileSdkVersion 36`, `targetSdkVersion 36`

---

## Golden Rule

**Never edit files under `android/app/src/main/assets/public/` directly.**
They are generated by `npm run build:android` and will be overwritten on the next build.

---

## Build Sequence

### After any frontend change
```bash
# Step 1 — always run this first
npm run build:android   # = npm run build && npx cap sync android

# Step 2 — open Android Studio
npm run cap:open

# Step 3 — in Android Studio
# Build → Generate Signed Bundle/APK → Android App Bundle
# Select the release keystore from key.properties
```

### What `build:android` does
1. `npm run build` — Vite builds `dist/`
2. `npx cap sync android` — copies `dist/` into `android/app/src/main/assets/public/` and syncs plugins

Skipping step 1 means Android Studio builds against stale web assets.

---

## Version Bumping (required before every Play Store submission)

Both values live in [android/app/build.gradle](app/build.gradle):

```groovy
versionCode 1       // increment by 1 each release (integer, must be unique on Play)
versionName "1.0"   // human-readable semver shown to users
```

Rule: every AAB uploaded to Google Play must have a `versionCode` strictly greater than the previous upload.

---

## Signing

Signing credentials are local-only and never committed to git:
- `android/key.properties` — references the keystore path + alias + passwords
- `android/quickstack-release.jks` — the release keystore

`build.gradle` reads `key.properties` at build time. If the file is missing, the release build type will not sign the AAB.

**Never modify the signing configuration in `build.gradle`.**

---

## Release Checklist

1. `npm run build:android` — build fresh web assets
2. Bump `versionCode` and `versionName` in `app/build.gradle`
3. Open Android Studio: `npm run cap:open`
4. Build → Generate Signed Bundle/APK → Android App Bundle → use release keystore
5. AAB output lands in `android/app/release/` — do not commit this file
6. Upload AAB to Google Play Console → Internal Testing track
7. Validate on device before promoting to a wider track

---

## What Not to Touch

| Path | Why |
|------|-----|
| `android/app/src/main/assets/public/` | Generated by build — overwritten on every sync |
| `android/key.properties` | Local only — never commit |
| `android/quickstack-release.jks` | Local only — never commit |
| `android/app/release/` | Build output — never commit |
| Signing config in `build.gradle` | Must not be modified |

---

## Capacitor Plugin Notes
- Camera access goes through Capacitor's native bridge (`CameraCapture.tsx` → Capacitor Camera plugin)
- Deep links are configured in `src/lib/capacitorSetup.ts` and handled by the `App` plugin
- Plugin changes require a `cap sync` to take effect — `npm run build:android` covers this

---

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|-------------|-----|
| App shows old UI on device | Stale assets | Run `npm run build:android` |
| Build fails on signing | Missing `key.properties` | Restore from secure backup |
| Deep link not working | Sync not run after config change | `npm run build:android` |
| `versionCode` conflict on Play | Forgot to bump | Increment `versionCode` in `build.gradle` |
